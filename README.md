## 프로젝트 개요

### 🎓 프로젝트 이름
**Prompt Manager** - AI 프롬프트 관리 및 활용 프로그램

### 📝 프로젝트 설명
AI 시대에 효과적인 프롬프트 작성과 관리는 필수 기술입니다.
이 프로그램은 다양한 상황에서 사용할 수 있는 **프롬프트를 체계적으로 관리**하고,
**카테고리별로 조회**하며, **즐겨찾기**로 자주 사용하는 프롬프트를 빠르게 찾을 수 있도록 도와줍니다.

### 🎯 주요 기능
- ✅ 프롬프트 추가 및 관리
- ✅ 카테고리별 조회
- ✅ 키워드 검색
- ✅ 즐겨찾기 기능
- ✅ 프롬프트 상세 보기
- ✅ 데이터 영속화 (JSON 저장)
- ✅ Markdown 내보내기

### 👥 대상 사용자
- AI 프롬프트를 자주 사용하는 학생
- 콘텐츠 크리에이터
- 마케팅 담당자
- 교육자

## 기능 설명

### 1️⃣ 프롬프트 추가 (Add Prompt)

**기능**: 새로운 프롬프트를 추가합니다.

**사용 방법**:
```
선택: 1

📝 새 프롬프트 추가
─────────────────────────────────────────

제목을 입력하세요: 강의안 작성
내용을 입력하세요: 다음 주제로 강의안을 작성해 주세요...
카테고리를 선택하세요:
1. 텍스트 생성
2. 이미지 생성
3. 일상 커뮤니케이션
4. 기타

선택: 1

✅ 프롬프트가 추가되었습니다!
```

**입력 규칙**:
- 제목: 필수 (빈 값 불가)
- 내용: 필수 (빈 값 불가)
- 카테고리: 기본 목록에서 선택 또는 새로 입력

---

### 2️⃣ 전체 프롬프트 목록 (List All)

**기능**: 모든 프롬프트를 목록으로 표시합니다.

**사용 방법**:
```
선택: 2

📋 전체 프롬프트 목록
─────────────────────────────────────────

[1] 강의안 작성 | 텍스트 생성 | ⭐
[2] 퀴즈 작성 | 텍스트 생성
[3] 설명글 작성 | 텍스트 생성 | ⭐
[4] 프레젠테이션 슬라이드 | 이미지 생성
[5] 인포그래픽 디자인 | 이미지 생성 | ⭐

총 5개의 프롬프트가 있습니다.
```

**표시 내용**:
- 번호: 프롬프트 ID
- 제목: 프롬프트 이름
- 카테고리: 분류
- ⭐: 즐겨찾기 표시

---

### 3️⃣ 카테고리별 조회 (Category Search)

**기능**: 특정 카테고리의 프롬프트만 조회합니다.

**사용 방법**:
```
선택: 3

🏷️  카테고리별 조회
─────────────────────────────────────────

사용 가능한 카테고리:
1. 텍스트 생성
2. 이미지 생성
3. 일상 커뮤니케이션
4. 기타

카테고리 선택: 1

📋 텍스트 생성 카테고리
─────────────────────────────────────────

[1] 강의안 작성 | ⭐
[2] 퀴즈 작성
[3] 설명글 작성 | ⭐

총 3개의 프롬프트가 있습니다.
```

---

### 4️⃣ 프롬프트 검색 (Search)

**기능**: 제목이나 내용에서 키워드를 검색합니다.

**사용 방법**:
```
선택: 4

🔍 프롬프트 검색
─────────────────────────────────────────

검색 키워드를 입력하세요: 강의

📋 검색 결과 (키워드: "강의")
─────────────────────────────────────────

[1] 강의안 작성 | 텍스트 생성 | ⭐

총 1개의 검색 결과가 있습니다.
```

**검색 대상**:
- 프롬프트 제목
- 프롬프트 내용
- 대소문자 구분 없음

---

### 5️⃣ 프롬프트 상세 보기 (Detail View)

**기능**: 선택한 프롬프트의 전체 내용을 표시합니다.

**사용 방법**:
```
선택: 5

👁️  프롬프트 상세 보기
─────────────────────────────────────────

프롬프트 번호를 입력하세요: 1

╔════════════════════════════════════════╗
║ 강의안 작성                             ║
╚════════════════════════════════════════╝

📌 카테고리: 텍스트 생성
⭐ 즐겨찾기: 예
📊 조회수: 5회

📝 전체 내용:
─────────────────────────────────────────

다음 주제로 강의안을 작성해 주세요:

[강의 정보]
- 주제: {주제}
- 대상: {대상}
- 시간: {시간}

[강의 목표]
학생들이 다음을 이해할 수 있도록 합니다:
1. {목표_1}
2. {목표_2}
...
```

---

### 6️⃣ 즐겨찾기 관리 (Favorites)

**기능**: 자주 사용하는 프롬프트를 즐겨찾기로 등록합니다.

**사용 방법**:
```
선택: 6

⭐ 즐겨찾기 관리
─────────────────────────────────────────

1. 즐겨찾기 추가/해제
2. 즐겨찾기 목록 보기
3. 뒤로 가기

선택: 1

프롬프트 번호를 입력하세요: 2

✅ [퀴즈 작성]이 즐겨찾기에 추가되었습니다!
```

**즐겨찾기 목록**:
```
선택: 6
선택: 2

⭐ 즐겨찾기 목록
─────────────────────────────────────────

[1] 강의안 작성 | 텍스트 생성
[2] 설명글 작성 | 텍스트 생성
[3] 프레젠테이션 슬라이드 | 이미지 생성

총 3개의 즐겨찾기가 있습니다.
```

---

### 7️⃣ 데이터 저장 (Save Data)

**기능**: 프롬프트를 JSON 파일로 저장합니다.

**사용 방법**:
```
선택: 7

💾 데이터 저장
─────────────────────────────────────────

✅ 프롬프트가 'prompts.json'에 저장되었습니다!
```

**저장 파일**:
- 파일명: `prompts.json`
- 위치: 프로그램과 같은 폴더
- 형식: JSON

---

### 8️⃣ Markdown 내보내기 (Export)

**기능**: 프롬프트를 Markdown 파일로 내보냅니다.

**사용 방법**:
```
선택: 8

📤 Markdown 내보내기
─────────────────────────────────────────

1. 전체 내보내기
2. 카테고리별 내보내기
3. 즐겨찾기만 내보내기

선택: 1

✅ 프롬프트가 'prompts_export.md'로 내보내졌습니다!
```

**생성 파일**:
- `prompts_export.md` (전체)
- `prompts_[카테고리].md` (카테고리별)

---
