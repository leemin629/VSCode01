## 프로젝트 개요

### 🎓 프로젝트 이름
**Prompt Manager** - AI 프롬프트 관리 및 활용 프로그램

### 📝 프로젝트 설명
AI 시대에 효과적인 프롬프트 작성과 관리는 필수 기술입니다.
이 프로그램은 다양한 상황에서 사용할 수 있는 **프롬프트를 체계적으로 관리**하고,
**카테고리별로 조회**하며, **즐겨찾기**로 자주 사용하는 프롬프트를 빠르게 찾을 수 있도록 도와줍니다.

### 🎯 주요 기능
- ✅ 프롬프트 추가 및 관리
- ✅ 카테고리별 조회
- ✅ 키워드 검색
- ✅ 즐겨찾기 기능
- ✅ 프롬프트 상세 보기
- ✅ 데이터 영속화 (JSON 저장)
- ✅ Markdown 내보내기

### 👥 대상 사용자
- AI 프롬프트를 자주 사용하는 학생
- 콘텐츠 크리에이터
- 마케팅 담당자
- 교육자

###  1-1. 강의안 생성 프롬프트
**목적**: 특정 주제의 체계적인 강의 자료 생성

**프롬프트**:
```
주제: [주제명]
대상: [학년/수준]
시간: [강의시간]

위 정보를 바탕으로 다음을 포함한 강의안을 작성하세요:
- 학습목표 (3-5개)
- 도입 (5분)
- 본론 (단계별 설명)
- 활동/실습
- 마무리 및 과제
```

**활용 예시**: 고등학교 수학, 대학 프로그래밍, 직무교육

---

###  1-2. 요약문 생성 프롬프트
**목적**: 긴 텍스트를 핵심만 추출하여 요약

**프롬프트**:
```
다음 텍스트를 요약하세요:
[원본 텍스트]

요약 방식:
- 분량: [단어수/문장수]
- 형식: [글머리/문단]
- 포함사항: 핵심 개념, 주요 수치, 결론
```

**활용 예시**: 논문 요약, 뉴스 기사 정리, 책 내용 요약

---

###  1-3. 설명글 작성 프롬프트
**목적**: 복잡한 개념을 쉽고 명확하게 설명

**프롬프트**:
```
개념: [설명할 개념]
대상 수준: [초급/중급/고급]
길이: [짧음/중간/길음]

다음을 포함하여 설명하세요:
- 정의 및 의미
- 실생활 예시 (2-3개)
- 핵심 특징
- 주의사항
```

**활용 예시**: 과학 개념 설명, 기술 용어 해석, 역사 사건 설명

---

###  1-4. 퀴즈 생성 프롬프트
**목적**: 학습 내용 확인 및 평가용 문제 생성

**프롬프트**:
```
학습 주제: [주제]
난이도: [쉬움/중간/어려움]
문제 수: [개수]
형식: [객관식/주관식/혼합]

다음을 포함한 퀴즈를 만드세요:
- 문제 (명확하고 구체적)
- 선택지 (객관식인 경우)
- 정답 및 해설
- 학습 포인트
```

**활용 예시**: 시험 대비 문제, 온라인 학습 평가, 자가진단 테스트

#  프롬프트 관리 프로그램

##  1. 프로젝트 소개
본 프로젝트는 다양한 프롬프트를 효율적으로 저장하고 관리하기 위해 제작한 **콘솔 기반 프롬프트 관리 프로그램**입니다.  
사용자는 프롬프트를 단순히 기록하는 데 그치지 않고, **카테고리별 분류**, **검색**, **추가**, **수정**, **삭제**, **즐겨찾기** 기능을 활용하여 보다 체계적으로 관리할 수 있습니다.

최근 AI 도구의 활용이 증가하면서, 한 번 작성한 프롬프트를 반복적으로 수정·재사용하는 일이 많아졌습니다.  
하지만 메모장이나 일반 문서에 프롬프트를 저장할 경우, 원하는 내용을 다시 찾기 어렵고 체계적으로 분류하기도 쉽지 않습니다.  
이러한 불편함을 해결하기 위해, 사용자가 자주 사용하는 프롬프트를 한곳에서 정리하고 관리할 수 있는 프로그램을 Python으로 구현하였습니다.

또한 프로그램의 데이터는 `prompts.json` 파일에 저장되므로, 프로그램을 종료한 뒤 다시 실행하더라도 기존 데이터가 그대로 유지됩니다.

---

##  2. 개발 목적
이 프로젝트의 주요 목적은 다음과 같습니다.

- 프롬프트를 카테고리별로 체계적으로 관리할 수 있도록 구현
- 저장된 프롬프트를 빠르게 조회하고 검색할 수 있도록 구성
- 자주 사용하는 프롬프트를 즐겨찾기 기능으로 별도 관리
- Python의 자료구조, 함수, 파일 입출력, 조건문, 반복문 등을 종합적으로 활용
- 실제로 동작하는 완성형 콘솔 프로그램 제작 경험 습득

즉, 단순한 CRUD 프로그램을 만드는 것을 넘어,  
**실제 사용자가 반복적으로 활용할 수 있는 실용적인 프롬프트 관리 도구를 구현하는 것**이 핵심 목표였습니다.

---

##  3. 개발 배경
프롬프트는 AI를 활용한 학습, 문서 작성, 기획, 업무 자동화 등 다양한 상황에서 중요한 역할을 합니다.  
예를 들어 학습용 질문 생성, 강의안 작성, 문제 출제, 기획안 정리, 마케팅 문구 생성 등은 한 번 작성한 뒤 끝나는 것이 아니라, 상황에 맞게 수정하며 반복적으로 사용하게 됩니다.

이 과정에서 다음과 같은 기능의 필요성이 커졌습니다.

- 프롬프트를 목적에 따라 분류할 수 있어야 함
- 제목이나 내용 일부만 기억해도 검색할 수 있어야 함
- 자주 사용하는 프롬프트를 따로 모아볼 수 있어야 함
- 잘못 저장한 프롬프트를 수정하거나 삭제할 수 있어야 함
- 프로그램 종료 후에도 데이터가 유지되어야 함

본 프로젝트는 이러한 실제 사용 환경을 고려하여 제작되었습니다.

---

##  4. 주요 기능

### 4.1 프롬프트 조회
- 카테고리를 먼저 선택한 뒤, 해당 카테고리에 속한 프롬프트 목록을 확인할 수 있습니다.
- 목록은 사용자가 보기 쉬운 **화면 번호** 기준으로 출력됩니다.
- 프롬프트를 선택하면 상세 정보가 출력됩니다.
- 상세 화면에서는 제목, 목적, 내용, 활용 예시, 즐겨찾기 여부를 확인할 수 있습니다.

###  4.2 프롬프트 검색
- 제목, 목적, 내용, 활용 예시, 카테고리를 기준으로 검색할 수 있습니다.
- 키워드 일부만 입력해도 관련 프롬프트를 찾을 수 있습니다.
- 검색 결과에서도 원하는 프롬프트를 선택하여 상세 내용을 확인할 수 있습니다.

###  4.3 프롬프트 추가
- 새 프롬프트를 추가할 때 먼저 카테고리를 선택합니다.
- 이후 제목, 목적, 내용, 활용 예시를 입력하여 저장합니다.
- 프롬프트의 내부 ID는 카테고리 기준으로 자동 생성됩니다.
- 예: `1-1`, `1-2`, `2-1`

###  4.4 프롬프트 수정
- 저장된 프롬프트를 선택한 뒤 제목, 목적, 내용, 활용 예시를 수정할 수 있습니다.
- 수정하지 않을 항목은 엔터를 입력하여 기존 값을 그대로 유지할 수 있습니다.

###  4.5 프롬프트 삭제
- 삭제할 프롬프트를 선택한 후 한 번 더 확인 과정을 거쳐 삭제합니다.
- 이를 통해 실수로 중요한 데이터를 삭제하는 상황을 줄일 수 있습니다.

###  4.6 즐겨찾기 기능
- 프롬프트 상세 화면에서 즐겨찾기 추가 및 해제가 가능합니다.
- 즐겨찾기 목록만 따로 확인할 수 있어 자주 사용하는 프롬프트를 빠르게 찾을 수 있습니다.

###  4.7 JSON 자동 저장 및 불러오기
- 프로그램 시작 시 `prompts.json` 파일을 자동으로 불러옵니다.
- 프롬프트 추가, 수정, 삭제, 즐겨찾기 변경 시 즉시 JSON 파일에 반영됩니다.
- 별도의 저장 버튼 없이도 데이터가 자동으로 유지됩니다.

##  5. 프로그램 구성 방식
본 프로그램은 **메뉴 기반 콘솔 인터페이스**로 구성되어 있습니다.  
사용자는 메인 메뉴에서 원하는 기능을 선택한 뒤, 각 화면에서 번호 입력을 통해 세부 작업을 수행할 수 있습니다.

특히 다음과 같은 구조적 특징을 반영하였습니다.

- **사용자 화면 번호와 내부 저장 ID를 분리**
- **카테고리 선택 후 목록을 보여주는 계층형 메뉴 구조 적용**
- **기능별 함수 분리를 통한 가독성과 유지보수성 향상**
- **JSON 파일 기반 저장 구조로 데이터 지속성 확보**

이러한 구성 덕분에 단순한 실습용 코드가 아니라, 실제 사용 가능한 수준의 콘솔 프로그램 형태로 완성할 수 있었습니다.

##  6. 카테고리 구성
현재 프로그램에는 다음과 같은 카테고리가 포함되어 있습니다.

1. 학습/교육
2. 비즈니스 디자인

각 카테고리의 예시는 다음과 같습니다.

- **학습/교육**: 문제 생성, 강의안 작성, 개념 설명, 학습 계획 프롬프트
- **비즈니스 디자인**: 기획안 정리, 아이디어 구조화, 마케팅 문구 작성 프롬프트

카테고리 분류를 통해 사용자는 프롬프트를 보다 체계적으로 관리할 수 있습니다.

## 10. 데이터 구조 설명
이 프로그램은 각 프롬프트를 하나의 딕셔너리 형태로 관리하며,  
여러 개의 프롬프트를 리스트로 묶어 `prompts.json` 파일에 저장합니다.

각 프롬프트는 다음과 같은 정보를 가집니다.

- `id` : 프롬프트의 내부 식별자

- `purpose` : 프롬프트 사용 목적
- `content` : 실제 프롬프트 내용
- `example` : 활용 예시
- `favorite` : 즐겨찾기 여부

    "content": "주제: [주제명]\n대상: [학년/수준]\n시간: [강의시간]\n\n위 정보를 바탕으로 다음을 포함한 강의안을 작성하세요:\n- 학습목표\n- 도입\n- 본론\n- 활동/실습\n- 마무리 및 과제",
    "example": "고등학교 수학, 대학 프로그래밍, 직무교육",

  },
  {
    "id": "2-1",
    "category": "비즈니스 디자인",
    "title": "기획 아이디어 정리 프롬프트",
    "purpose": "아이디어를 구조화하여 기획안 형태로 정리",

이처럼 데이터를 구조화함으로써 조회, 검색, 수정, 삭제 기능을 안정적으로 구현할 수 있습니다.

## 11. ID 관리 방식
본 프로그램에서는 **사용자에게 보여주는 번호**와 **실제로 저장되는 내부 ID**를 분리하여 사용합니다.

### 11.1 화면 번호
프롬프트 목록을 출력할 때 사용자가 선택하기 쉽도록 보여주는 번호입니다.

예:
```text
1. 강의안 생성 프롬프트
2. 개념 설명 프롬프트
3. 문제 생성 프롬프트
```

### 11.2 내부 ID
실제 데이터에는 카테고리 번호와 순번을 조합한 ID가 저장됩니다.

예:
- `1-1`
- `1-2`
- `2-1`

### 11.3 분리한 이유
이와 같이 번호를 분리하면 다음과 같은 장점이 있습니다.

- 사용자 입장에서는 단순한 숫자 선택 방식으로 이용 가능
- 프로그램 내부에서는 고유 식별자를 안정적으로 유지 가능
- 카테고리별 정리와 데이터 관리가 쉬움
- 수정 및 삭제 시 정확한 데이터 식별 가능

이는 사용 편의성과 데이터 관리의 일관성을 동시에 고려한 설계입니다.

## 12. 주요 구현 내용

### 12.1 기능별 함수 분리
조회, 검색, 추가, 수정, 삭제, 저장, 불러오기, 즐겨찾기 기능을 각각 함수로 분리하여 구현하였습니다.

장점:
- 코드 가독성 향상
- 유지보수 용이
- 중복 코드 감소
- 오류 발생 시 원인 파악이 쉬움

### 12.2 계층형 메뉴 구조
콘솔 프로그램의 특성상 사용 흐름이 복잡해지지 않도록,  
카테고리 선택 → 목록 선택 → 상세 확인의 단계적 구조를 적용하였습니다.

장점:
- 사용자가 현재 위치를 쉽게 이해할 수 있음
- 한 번에 너무 많은 정보를 보여주지 않아 가독성이 높음
- 기능 흐름이 자연스러움

### 12.3 자동 저장 처리
프롬프트 추가, 수정, 삭제, 즐겨찾기 변경이 발생할 때마다 즉시 `prompts.json` 파일에 저장되도록 구현하였습니다.

장점:
- 프로그램 종료 후에도 데이터 유지
- 사용자가 저장 여부를 따로 신경 쓰지 않아도 됨
- 실사용 환경에서 편의성이 높음

### 12.4 검색 기능 구성
검색은 단순히 제목만 대상으로 하지 않고 다음 항목들을 모두 포함하도록 구현하였습니다.

- 제목
- 목적
- 내용
- 활용 예시
- 카테고리

이를 통해 사용자가 정확한 제목을 기억하지 못해도 원하는 프롬프트를 쉽게 찾을 수 있습니다.

## 14. 프로그램의 장점

### 14.1 실용성
프롬프트를 반복적으로 사용하는 사용자에게 실제로 도움이 되는 기능을 포함하고 있습니다.

### 14.2 직관적인 사용 방식
복잡한 명령어 대신 번호 입력 기반의 메뉴 방식을 사용하여 초보자도 쉽게 이용할 수 있습니다.

### 14.3 데이터 영속성
JSON 파일 저장 구조를 사용하여 프로그램을 종료해도 데이터가 유지됩니다
