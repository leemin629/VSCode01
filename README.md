GitHub 저장소: [https://github.com/leemin629/VSCode01](https://github.com/leemin629/VSCode01)

##  1. 프로젝트 소개

이 프로젝트는 Python으로 제작한 **콘솔 기반 프롬프트 관리 프로그램**입니다.

사용자는 터미널에서 메뉴 번호를 입력하여 프롬프트를 관리할 수 있습니다.  
프롬프트 추가, 목록 조회, 카테고리별 조회, 검색, 상세 보기, 수정, 삭제, 즐겨찾기 기능을 사용할 수 있습니다.

프로그램 실행 중에 추가하거나 수정한 프롬프트와 즐겨찾기 상태는 실행 중에는 유지되며, 프로그램을 종료하면 초기 상태로 돌아갑니다.

##  4. 주요 기능

###  4.1 메인 메뉴

프로그램을 실행하면 메뉴가 출력됩니다.  
사용자는 번호를 입력하여 원하는 기능을 선택할 수 있습니다.

주요 메뉴는 다음과 같습니다.


- 전체 프롬프트 조회
- 카테고리별 조회
- 프롬프트 검색
- 새 프롬프트 추가
- 프롬프트 수정
- 프롬프트 삭제
- 즐겨찾기 목록
- 프로그램 종료

프롬프트 상세 보기는 전체 목록, 카테고리별 목록, 검색 결과에서 프롬프트 번호를 선택하면 확인할 수 있습니다.

즐겨찾기 추가/제거 기능은 프롬프트 상세 정보 화면에서 사용할 수 있습니다.

잘못된 값을 입력하면 안내 메시지를 출력하고 다시 입력을 받습니다

---

###  4.2 기본 프롬프트 데이터

프로그램 시작 시 기본 프롬프트가 미리 등록되어 있습니다.

각 프롬프트는 다음 정보를 포함합니다.

- ID
- 제목
- 카테고리
- 목적
- 내용
- 예시
- 즐겨찾기 여부

기본 데이터는 리스트와 딕셔너리를 사용하여 관리합니다.

```python
{
    "id": "1-1",
    "category": "학습/교육",
    "title": "강의안 작성 프롬프트",
    "purpose": "수업용 강의안 작성",
    "content": "...",
    "example": "...",
    "favorite": False
}
```

---

###  4.3 프롬프트 추가

사용자는 새로운 프롬프트를 추가할 수 있습니다.

입력 항목은 다음과 같습니다.

- 제목
- 내용
- 카테고리
- 목적
- 예시

입력값이 비어 있으면 다시 입력하도록 처리했습니다.  
추가된 프롬프트는 프로그램 실행 중 리스트에 저장됩니다.

---

###  4.4 프롬프트 목록 보기

저장된 모든 프롬프트를 번호와 함께 출력합니다.

출력 정보는 다음과 같습니다.

- 번호
- 제목
- 카테고리
- 즐겨찾기 여부

즐겨찾기된 프롬프트는 `⭐` 표시로 확인할 수 있습니다.

---

###  4.5 카테고리별 조회

카테고리 목록을 보여주고, 사용자가 선택한 카테고리에 해당하는 프롬프트만 출력합니다.

해당 카테고리에 프롬프트가 없으면 안내 메시지를 출력합니다.

---

###  4.6 프롬프트 검색

키워드를 입력하면 제목, 내용, 목적 등에 해당 키워드가 포함된 프롬프트를 검색합니다.

검색 결과가 있으면 목록으로 출력하고, 결과가 없으면 안내 메시지를 출력합니다.

---

###  4.7 프롬프트 상세 보기

프롬프트 번호를 입력하면 해당 프롬프트의 전체 정보를 확인할 수 있습니다.

상세 보기에서 출력되는 정보는 다음과 같습니다.

- 제목
- 카테고리
- 목적
- 내용
- 예시
- 즐겨찾기 여부

---

###  4.8 즐겨찾기 기능

프롬프트 번호를 입력하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

즐겨찾기 상태는 `True / False` 값으로 관리되며, 목록에서는 `⭐` 표시로 보여줍니다.

또한 즐겨찾기된 프롬프트만 따로 모아서 확인할 수 있습니다.

---

###  4.9 프롬프트 수정 및 삭제

보너스 기능으로 프롬프트 수정과 삭제 기능을 구현했습니다.

- 프롬프트 수정: 기존 프롬프트의 제목, 내용, 카테고리 등을 변경
- 프롬프트 삭제: 선택한 프롬프트를 목록에서 제거

---

###  4.10 전역 종료 명령어

프로그램 실행 중 입력창에서 아래 명령어를 입력하면 즉시 종료됩니다.

```text
q
quit
exit
```

이를 위해 `safe_input()` 함수를 만들어 모든 입력을 통합 관리했습니다.

##  5. 등록된 프롬프트 카테고리

프로그램에는 여러 종류의 프롬프트를 관리할 수 있도록 카테고리를 구성했습니다.

예시 카테고리는 다음과 같습니다.

| 카테고리 | 설명 |
|---|---|

| 비즈니스 디자인 | 프레젠테이션, 포스터, 브랜드 콘셉트, 마케팅 문구 관련 프롬프트 |

사용자가 새 프롬프트를 추가할 때 원하는 카테고리를 입력할 수 있습니다.

##  6. 코드 구조

프로그램은 기능별로 함수를 분리하여 작성했습니다.

대표적인 함수는 다음과 같습니다.

| 함수명 | 역할 |
|---|---|
| `main_menu()` | 메인 메뉴 출력 및 사용자 선택 처리 |
| `safe_input()` | 입력값 처리 및 종료 명령어 확인 |
| `safe_input_non_empty()` | 빈 입력 방지 |
| `show_prompts()` | 전체 프롬프트 목록 출력 |
| `display_prompt_detail()` | 프롬프트 상세 보기 |
| `search_prompts()` | 키워드 기반 프롬프트 검색 |
| `add_prompt()` | 새 프롬프트 추가 |
| `update_prompt()` | 기존 프롬프트 수정 |
| `delete_prompt()` | 프롬프트 삭제 |
| `toggle_favorite()` | 즐겨찾기 추가 및 해제 |
| `show_favorites()` | 즐겨찾기 목록 출력 |

하나의 함수에 모든 기능을 넣지 않고, 기능별로 분리하여 코드의 가독성과 유지보수성을 높였습니다.

##  7. GitHub 저장소 관리

이 프로젝트는 Git과 GitHub를 사용하여 버전 관리를 진행했습니다.

수행한 작업은 다음과 같습니다.

- GitHub 저장소 생성
- 로컬 프로젝트 폴더에서 Git 초기화
- 원격 저장소 연결
- README.md 작성
- `.gitignore` 파일 관리
- 기능 단위 커밋 작성
- 브랜치 생성 및 병합
- GitHub로 push
- `git log --oneline --graph`로 커밋 기록 확인

---

##  8. 주요 Git 명령어 정리

| 명령어 | 설명 |
|---|---|
| `git init` | 현재 폴더를 Git 저장소로 초기화 |
| `git add .` | 변경된 파일을 스테이징 영역에 추가 |
| `git commit -m "메시지"` | 변경 내용을 커밋으로 저장 |
| `git push` | 로컬 커밋을 GitHub 원격 저장소에 업로드 |
| `git pull` | GitHub 원격 저장소의 변경 사항을 가져와 병합 |
| `git checkout -b 브랜치명` | 새 브랜치를 만들고 이동 |
| `git checkout main` | main 브랜치로 이동 |
| `git merge 브랜치명` | 다른 브랜치의 작업 내용을 현재 브랜치에 병합 |
| `git clone 저장소주소` | 원격 저장소를 로컬에 복제 |
| `git log --oneline --graph` | 커밋 기록을 한 줄 그래프 형태로 확인 |

##  12. 실행 결과 예시

프로그램 실행 시 다음과 같은 방식으로 메인 메뉴가 출력됩니다.

```text
============================================================
🧠 프롬프트 관리 프로그램
============================================================
1. 전체 프롬프트 조회
2. 카테고리별 조회
3. 프롬프트 검색
4. 새 프롬프트 추가
5. 프롬프트 수정
6. 프롬프트 삭제
7. 즐겨찾기 목록
q. 종료
메뉴 선택:
```

사용자는 메뉴 번호를 입력하여 원하는 기능을 실행할 수 있습니다.  
프로그램을 종료하려면 메인 메뉴에서 `q`를 입력합니다.

---

### 12.1 전체 프롬프트 조회 예시

메인 메뉴에서 `1`을 입력하면 전체 프롬프트 목록이 출력됩니다.

```text
메뉴 선택: 1

============================================================
📋 전체 프롬프트 목록
============================================================
1. [1-1] 강의안 생성 프롬프트 (학습/교육)
2. [1-2] 요약문 생성 프롬프트 (학습/교육)
3. [1-3] 설명글 작성 프롬프트 (학습/교육)
4. [1-4] 퀴즈 생성 프롬프트 (학습/교육)
5. [2-1] 프레젠테이션 슬라이드 프롬프트 (비즈니스 디자인)
6. [2-2] 포스터 디자인 프롬프트 (비즈니스 디자인)
7. [2-3] 브랜드 콘셉트 프롬프트 (비즈니스 디자인)
8. [2-4] 마케팅 문구 작성 프롬프트 (비즈니스 디자인)
0. 돌아가기
q. 프로그램 종료
번호를 선택하세요 (0: 돌아가기):
```

전체 프롬프트 목록에서는 각 프롬프트의 번호, ID, 제목, 카테고리를 확인할 수 있습니다.

---

### 12.2 프롬프트 상세 정보 조회 예시

전체 프롬프트 목록에서 번호를 선택하면 해당 프롬프트의 상세 정보를 확인할 수 있습니다.

```text
번호를 선택하세요 (0: 돌아가기): 2

============================================================
📌 프롬프트 상세 정보
============================================================
ID: 1-2
```

### 12.5 입력값 넣어 완성된 프롬프트 보기 예시

프롬프트 상세 정보 화면에서 `2`를 선택하면 프롬프트 안의 대괄호 부분에 사용자가 직접 값을 입력하여 완성된 프롬프트를 확인할 수 있습니다.

예를 들어 강의안 생성 프롬프트에는 다음과 같은 입력값이 필요합니다.

```text
주제: [주제명]
대상: [학년/수준]
시간: [강의시간]
```

사용자는 `[주제명]`, `[학년/수준]`, `[강의시간]`에 들어갈 값을 직접 입력할 수 있습니다.

예시 입력:

```text
[주제명]에 넣을 값을 입력하세요: 파이썬 반복문
[학년/수준]에 넣을 값을 입력하세요: 고등학생
[강의시간]에 넣을 값을 입력하세요: 50분
```

완성된 프롬프트 예시는 다음과 같습니다.

```text
주제: 파이썬 반복문
대상: 고등학생
시간: 50분

위 정보를 바탕으로 다음을 포함한 강의안을 작성하세요:
- 학습목표
- 도입
- 본론
- 활동/실습
- 마무리 및 과제
```

이 기능을 통해 기본 프롬프트를 사용자가 원하는 상황에 맞게 완성할 수 있습니다.

### 12.7 프롬프트 검색 예시

```text
🔍 검색 결과
```

검색 결과에서도 번호를 선택하면 해당 프롬프트의 상세 정보를 확인할 수 있습니다.

검색 결과가 없는 경우에는 안내 메시지를 출력합니다.

```text
검색어를 입력하세요: 없는단어

```

### 12.12 잘못된 입력 처리 예시

메뉴에 없는 값을 입력하면 안내 메시지를 출력하고 다시 입력을 받습니다.

```text
메뉴 선택: 99

잘못된 입력입니다. 다시 선택해주세요.
```

숫자를 입력해야 하는 곳에 문자를 입력한 경우에도 프로그램이 종료되지 않고 다시 입력을 받도록 처리했습니다.

```text
번호를 선택하세요: abc

숫자를 입력해주세요.
```

빈 값을 입력할 수 없는 항목에서는 다시 입력하도록 처리했습니다.

```text
제목을 입력하세요:

빈 값은 입력할 수 없습니다. 다시 입력해주세요.
```
