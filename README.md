## 프로젝트 개요

### 🎓 프로젝트 이름
**Prompt Manager** - AI 프롬프트 관리 및 활용 프로그램

### 📝 프로젝트 설명
AI 시대에 효과적인 프롬프트 작성과 관리는 필수 기술입니다.
이 프로그램은 다양한 상황에서 사용할 수 있는 **프롬프트를 체계적으로 관리**하고,
**카테고리별로 조회**하며, **즐겨찾기**로 자주 사용하는 프롬프트를 빠르게 찾을 수 있도록 도와줍니다.

### 🎯 주요 기능
- ✅ 프롬프트 추가 및 관리
- ✅ 카테고리별 조회
- ✅ 키워드 검색
- ✅ 즐겨찾기 기능
- ✅ 프롬프트 상세 보기
- ✅ 데이터 영속화 (JSON 저장)
- ✅ Markdown 내보내기

### 👥 대상 사용자
- AI 프롬프트를 자주 사용하는 학생
- 콘텐츠 크리에이터
- 마케팅 담당자
- 교육자

#  📚 프롬프트 카테고리 및 상세 명세

##  1️⃣ 학습/교육 중심

###  1-1. 강의안 생성 프롬프트
**목적**: 특정 주제의 체계적인 강의 자료 생성

**프롬프트**:
```
주제: [주제명]
대상: [학년/수준]
시간: [강의시간]

위 정보를 바탕으로 다음을 포함한 강의안을 작성하세요:
- 학습목표 (3-5개)
- 도입 (5분)
- 본론 (단계별 설명)
- 활동/실습
- 마무리 및 과제
```

**활용 예시**: 고등학교 수학, 대학 프로그래밍, 직무교육

---

###  1-2. 요약문 생성 프롬프트
**목적**: 긴 텍스트를 핵심만 추출하여 요약

**프롬프트**:
```
다음 텍스트를 요약하세요:
[원본 텍스트]

요약 방식:
- 분량: [단어수/문장수]
- 형식: [글머리/문단]
- 포함사항: 핵심 개념, 주요 수치, 결론
```

**활용 예시**: 논문 요약, 뉴스 기사 정리, 책 내용 요약

---

###  1-3. 설명글 작성 프롬프트
**목적**: 복잡한 개념을 쉽고 명확하게 설명

**프롬프트**:
```
개념: [설명할 개념]
대상 수준: [초급/중급/고급]
길이: [짧음/중간/길음]

다음을 포함하여 설명하세요:
- 정의 및 의미
- 실생활 예시 (2-3개)
- 핵심 특징
- 주의사항
```

**활용 예시**: 과학 개념 설명, 기술 용어 해석, 역사 사건 설명

---

###  1-4. 퀴즈 생성 프롬프트
**목적**: 학습 내용 확인 및 평가용 문제 생성

**프롬프트**:
```
학습 주제: [주제]
난이도: [쉬움/중간/어려움]
문제 수: [개수]
형식: [객관식/주관식/혼합]

다음을 포함한 퀴즈를 만드세요:
- 문제 (명확하고 구체적)
- 선택지 (객관식인 경우)
- 정답 및 해설
- 학습 포인트
```

**활용 예시**: 시험 대비 문제, 온라인 학습 평가, 자가진단 테스트

---

##  2️⃣ 비즈니스 디자인

###  2-1. 프레젠테이션 슬라이드 프롬프트
**목적**: 효과적인 비즈니스 프레젠테이션 슬라이드 구성

**프롬프트**:
```
주제: [발표 주제]
청중: [대상 청중]
슬라이드 수: [개수]

다음 구조로 슬라이드를 설계하세요:
- 제목 슬라이드 (제목, 부제, 날짜)
- 개요 (주요 내용 3-5개)
- 본론 (각 항목별 상세 설명)
- 결론 (핵심 메시지, CTA)
- 참고자료

각 슬라이드마다:
- 제목
- 핵심 내용 (3-5줄)
- 시각화 요소 제안
```

**활용 예시**: 사업 제안, 분기 보고, 투자 설명회

---

###  2-2. 포스터 디자인 프롬프트
**목적**: 시각적으로 매력적인 포스터 콘셉트 개발

**프롬프트**:
```
포스터 주제: [주제]
목적: [홍보/모집/공지]
타겟: [대상층]
크기: [A4/A3/자유]

포스터 구성안:
- 헤드라인 (임팩트 있는 문구)
- 부제 (설명 문구)
- 핵심 이미지 설명
- 본문 내용 (3-5줄)
- CTA (행동 유도)
- 색상 제안
- 레이아웃 설명
```

**활용 예시**: 행사 홍보, 채용 공고, 제품 광고

---

###  2-3. 명함 디자인 프롬프트
**목적**: 전문적이고 기억에 남는 명함 제작

**프롬프트**:
```
직책: [직책]
회사: [회사명]
업종: [업종]
이미지: [회사 이미지/스타일]

명함 구성:
- 정면 (이름, 직책, 회사명, 연락처)
- 후면 (회사 소개, 주요 서비스)
- 색상 스킴 (메인/서브 색상)
- 폰트 스타일 제안
- 재질/마감 제안
- 레이아웃 설명
```

**활용 예시**: 개인 사업가, 직원 명함, 프리랜서 명함

---

###  2-4. 로고 디자인 프롬프트
**목적**: 브랜드 정체성을 반영한 로고 개념 개발

**프롬프트**:
```
브랜드명: [회사/상품명]
업종: [업종]
브랜드 가치: [핵심 가치 3개]
타겟층: [대상층]

로고 디자인 방향:
- 컨셉 설명 (심볼의 의미)
- 형태 제안 (기하학적/유기적/텍스트)
- 색상 의미 (각 색상의 의미)
- 폰트 스타일
- 응용 방안 (명함, 웹, 간판 등)
- 차별성 (경쟁사 대비)
```

**활용 예시**: 스타트업 로고, 제품 브랜드, 개인 사업 로고

##  📞 문제 해결

###  Q1: 프로그램 실행 시 "ModuleNotFoundError" 발생
**A:** 가상환경이 활성화되었는지 확인하세요.
```bash
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

###  Q2: JSON 파일이 저장되지 않음
**A:** 프로그램 종료 시 `save_prompts()` 함수가 호출되는지 확인하세요.

### Q3: Git 푸시 시 "Permission denied" 오류
**A:** SSH 키가 올바르게 설정되었는지 확인하세요.
```bash
ssh -T git@github.com
```
